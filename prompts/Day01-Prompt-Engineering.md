# Prompt Engineering

## What is Prompt?

A prompt is an instruction given to an AI model to perform a task.

---

## Types of Prompt

- Basic Prompt
- Role Prompt
- Context Prompt
- Task Prompt

---

## Rule

Better Prompt = Better Output
## Professional Prompt Structure

### 1. Role
Defines who the AI should act as.

### 2. Task
Defines what AI should do.

### 3. Context
Provides background information.

### 4. Rules
Defines constraints.

### 5. Output Format
Specifies how the answer should be returned.

---

### Example

Role:
You are an AI Engineer.

Task:
Write a professional email.

Context:
Meeting confirmation.

Rules:
Professional
Short
Polite

Output:
Subject
Email
